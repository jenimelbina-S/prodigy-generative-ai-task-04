# Prodigy Generative AI - Task 04

## Image-to-Image Translation using cGAN (Pix2Pix)

This project demonstrates image-to-image translation using a Conditional Generative Adversarial Network (cGAN) based on the Pix2Pix architecture.

### Technologies Used
- Python
- TensorFlow
- Keras
- Google Colab
- Matplotlib
- NumPy

### Dataset
Used the Facades paired-image dataset for training and image translation.

### Implementation
- Downloaded and prepared the paired image dataset.
- Resized and normalized input and target images.
- Built a U-Net based Generator.
- Built a PatchGAN Discriminator.
- Configured generator and discriminator loss functions.
- Trained the Pix2Pix model for 2 epochs.
- Generated and saved an output image.

### Output
Generated an image using the trained Pix2Pix model and compared it with the input and expected target images.
